# Подключение живой ленты Instagram

Сайт умеет показывать реальные посты из Instagram, но для этого нужен
небольшой бэкенд — статический сайт (GitHub Pages) не может безопасно
хранить секретный токен доступа. Ниже — все шаги, которые должен сделать
владелец аккаунта Instagram (только он может выдать доступ к своему
аккаунту, я не могу сделать этот шаг за него).

Всё бесплатно, весь процесс занимает 15–20 минут.

## Шаг 1. Сделать аккаунт Instagram бизнес-профилем

1. В приложении Instagram → **Настройки → Аккаунт → Переключиться на
   профессиональный аккаунт** → выбрать «Бизнес».
2. Привязать его к странице Facebook ресторана (если её нет — создать
   пустую страницу за 1 минуту, Facebook попросит это сделать сам).

## Шаг 2. Создать приложение в Meta for Developers

1. Зайти на https://developers.facebook.com/apps и создать новое
   приложение типа **«Business»**.
2. В панели приложения добавить продукт **Instagram Graph API**.
3. В разделе **Instagram → Basic Display / API setup** привязать
   аккаунт ресторана, который сделали бизнес-профилем на шаге 1.
4. Через встроенный **Graph API Explorer** сгенерировать токен доступа
   с правами `instagram_basic` и `pages_show_list`, затем обменять его
   на **долгоживущий токен (long-lived token, живёт 60 дней)** — Meta
   даёт для этого отдельную кнопку/эндпоинт в том же интерфейсе.
5. Сохранить два значения — они понадобятся на шаге 4:
   - **IG_ACCESS_TOKEN** — сам долгоживущий токен;
   - **IG_USER_ID** — числовой ID аккаунта Instagram.

## Шаг 3. Развернуть бэкенд на Netlify

1. Зайти на https://app.netlify.com и войти через GitHub.
2. **Add new site → Import an existing project** → выбрать репозиторий
   `zumrud2006/Pirosmani`, ветку `claude/peaceful-volta-45hh9p` (или
   основную ветку, если работа уже туда влита).
3. Настройки сборки Netlify подхватит сам из `netlify.toml` — просто
   нажать **Deploy**.
4. Сам сайт при этом продолжает жить на GitHub Pages как раньше —
   Netlify тут нужен только ради серверлесс-функции.

## Шаг 4. Добавить секреты в Netlify

В настройках задеплоенного сайта: **Site configuration → Environment
variables → Add a variable**, добавить:

| Ключ | Значение |
|---|---|
| `IG_ACCESS_TOKEN` | токен из шага 2 |
| `IG_USER_ID` | ID аккаунта из шага 2 |

**(необязательно, но рекомендуется)** — чтобы токен обновлял себя сам
каждые 60 дней и не пришлось повторять шаг 2 вручную, добавить ещё два
значения:

| Ключ | Значение |
|---|---|
| `NETLIFY_AUTH_TOKEN` | личный токен: **User settings → Applications → New access token** |
| `NETLIFY_SITE_ID` | **Site configuration → General → Site ID** этого же сайта |

После сохранения переменных — **Deploys → Trigger deploy**, чтобы
функция их подхватила.

## Шаг 5. Подключить адрес функции к сайту

1. В Netlify скопировать адрес сайта, например
   `https://pirosmani-feed.netlify.app`.
2. В файле `index.html` (в самом низу, рядом с остальными `<script>`)
   вписать его в готовую строку:

   ```html
   <script>
     window.INSTAGRAM_FEED_ENDPOINT = "https://pirosmani-feed.netlify.app/.netlify/functions/instagram-feed";
   </script>
   ```

3. Закоммитить и запушить — лента на сайте начнёт подтягивать
   настоящие посты автоматически (обновление раз в час).

## Что будет, если что-то не настроено

Ничего не сломается. Пока `INSTAGRAM_FEED_ENDPOINT` пустой или бэкенд
недоступен, секция Instagram молча остаётся такой же, как сейчас —
с вручную вставленными фото и плейсхолдерами.
